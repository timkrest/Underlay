# Как это устроено

[English version](how-it-works.md)

## Окна

Underlay находит два окна: собственное окно оверлея, на которое ставится системное размытие, и
host-окно под ним, с которого делается снимок.

| Откуда вызвано | Своё окно | Host-окно | Лучший источник |
|----------------|-----------|-----------|-----------------|
| `Dialog`, `AlertDialog` из Material 3 | окно диалога | окно активити | `SystemBlur` |
| `Popup`, `PopupWindow`, `DropdownMenu` | корневая View через `WindowManager` | окно активити | `SystemBlur` |
| `ModalBottomSheet` | своё окно | окно активити | `SystemBlur` |
| View-`Dialog`, `DialogFragment`, `BottomSheetDialog` | окно диалога | окно активити | `SystemBlur` |
| Прозрачная или плавающая активити | окно активити | нет, под ней окно другой активити | `SystemBlur` |
| Оверлей внутри окна активити | нет | нет | `Fallback` |

Без своего окна оверлей снимал бы сам себя, поэтому рисует `fallback`.

## Системное размытие

`FLAG_BLUR_BEHIND` и `blurBehindRadius` ставятся на окно оверлея, и система размывает всё за ним
вживую и бесплатно для приложения. Underlay слушает
`WindowManager.addCrossWindowBlurEnabledListener` и переключается между `SystemBlur` и `Snapshot`,
когда межоконное размытие включается и выключается. Если окно не приняло флаг, используется
`Snapshot`.

## Снимок

Host-окно копируется в четверть размера, когда нарисован запрошенный кадр: через `PixelCopy` на API
26+, через `decorView.draw()` ниже. Копия размывается через `RenderEffect` на API 31+ и тремя
проходами box-блюра на `Dispatchers.Default` ниже. Пока снимка нет, рисуется только тинт; первый
снимок проявляется за 200 мс. Неудачный перезахват оставляет старый снимок, если host-окно не
сменило размер.

`blurRadius` — тот же радиус, что принимают `Modifier.blur`, `blurBehindRadius` и
`RenderEffect.createBlurEffect`, в пикселях окна. Снимок переводит его в гауссову сигму платформы,
`0.57735 * radius + 0.5`, с поправкой на четверть масштаба, поэтому `SystemBlur` и `Snapshot`
размывают одинаково. Box-блюр берёт радиус, три прохода которого ближе всего к этой сигме.

## Границы

Underlay работает только на Android. На iOS диалоги Compose живут в той же иерархии, а размытие
закрывает `UIVisualEffectView`; на десктопе нет ни `FLAG_BLUR_BEHIND`, ни `PixelCopy`.
